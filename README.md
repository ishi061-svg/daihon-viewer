# 台本表示ツール

台本を貼り付けるだけで、タブレットにセリフを1ページずつ大きく表示するWebツールです。
収録や撮影のとき、少し離れた場所からでも台本が読めるように作りました。

## できること

- セリフを1ページずつ、画面の端まで入るいちばん大きな文字で表示（短いセリフほど大きく）
- 「名前：セリフ」と書くと、人ごとに色分け。名前には座布団（色つきの板）を敷ける
- 1行ごと・空行ごと・「---」などの記号ごとに、ページの区切り方を選べる
- 区切り・（ ）・名前をワンボタンで入力
- 文字の太さ・フチ・行間・改行のしかたを調整し、確認ウィンドウ（広い画面では右の列、狭い画面では台本の下）でその場で確認
- タップかスワイプでページをめくる。Androidでは自動で全画面・横向きに固定
- どの機器でも見られるよう、1ページを16:9のJPG画像にして保存（全ページまとめてZIP、または1枚だけ）

## 使い方

1. `index.html` をブラウザ（Chrome・Safari など）で開く
2. 台本を貼り付ける（例：`山田：こんにちは`）
3. 画面の下のバーにある「表示を始める」を押す

入力した台本や設定は、そのブラウザの中にだけ保存されます。外部には送りません。
（太字フォントは、ネットにつながっているときだけ Google Fonts から読み込みます）

## 使った技術

- HTML / CSS / JavaScript（ファイル1つで動作、ライブラリなし）
- Canvas で画像を描き、ZIP（無圧縮）もJavaScriptで作成
- Claude Code と一緒に制作
